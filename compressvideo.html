  • Untuk ukuran minimum: pakai Hemat Maks (H.265 + 480p + CRF 32).
  • Untuk kualitas terbaik: CRF 18–20 dengan H.264 pada resolusi asli.
  • Target ukuran pasti: pakai mode Target (MB).
  • Video sudah terkompres: jangan harap turun >30%.
  • File >500 MB: tutup tab lain untuk hemat RAM.
  • Preset custom: simpan setting favorit di tab Lanjutan.
  • FFmpeg gagal dimuat: cek koneksi internet. Coba refresh.
  • Out of memory: turunkan resolusi atau gunakan file lebih kecil.
  • Output lebih besar: video sudah optimal. Turunkan CRF/bitrate.
  • Server butuh COOP/COEP: deploy di server dengan header yang benar (lihat SETUP.md).
  • Subtitle hilang: output MP4 tidak menyimpan subtitle MKV. Gunakan MP4 sebagai input saja.
  • Cancel tidak bekerja: tunggu 3 detik — worker force-terminate otomatis.
