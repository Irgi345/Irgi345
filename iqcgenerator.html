PERTANYAAN UMUM

Tidak. Semua proses IQC Generator berjalan 100% di browser Anda menggunakan HTML5 Canvas dan html2canvas. Tidak ada data yang dikirim ke server manapun.

Pilih tab WhatsApp iOS, atur isi pesan, jam, tipe bubble, emoji reaction (👍❤️😂😮😢🙏), warna bubble. Preview akan menampilkan seperti screenshot iPhone saat long-press bubble pesan WhatsApp lengkap dengan context menu iOS. Klik Download HD PNG untuk menyimpan.

Pilih tab Instagram iOS, isi nama kontak, tambahkan pesan masuk/keluar, atur jam dan tampilan. Bubble otomatis mengikuti gaya gradient Instagram (ungu-pink-oranye) untuk pesan keluar dan abu-abu untuk pesan masuk.

Pastikan perangkat Anda memiliki font emoji native (Apple Color Emoji / Segoe UI Emoji / Noto Color Emoji). Kami sudah menetapkan font stack khusus agar emoji tampil native. Update OS/browser Anda jika emoji masih kotak.

PNG transparan & HD. Tombol Download PNG menghasilkan 2x (750×1624), tombol Download HD PNG menghasilkan 3x (1125×2436) — sangat tajam untuk diposting ke media sosial.
